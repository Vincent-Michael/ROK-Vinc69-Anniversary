# ROK Anniversary Shop Calculator

Interactive Rise of Kingdoms Anniversary Shop calculator.

## Features

- All 34 shop offers
- Quantity selection per item
- Artist Token cost calculation
- Collector Token cost calculation
- Search and category filters
- Token source overview
- Full-shop totals
